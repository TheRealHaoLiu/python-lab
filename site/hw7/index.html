Flow Control Lab

Until now Python ran every line, top to bottom. With if, a program makes decisions: it checks a condition, and runs a block of lines only when the condition is True.

if Two roads

if age >= 12: print("Big coaster!") else: print("Too small.")
  • A colon : ends every if, elif and else line.
  • The block under it is indented 4 spaces, all lines the same.
  • elif checks another condition; else catches the rest.

== Asking, not telling

age = 12 age == 12
  • = puts a value in a variable. == asks if two values are equal.
  • and: both sides must be True. or: at least one side.
  • None means “no value”: if myval == None:
  • "10" is a string, 10 is a number: not equal!
