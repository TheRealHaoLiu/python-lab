f-strings Lab

The class taught %s. Real Python today mostly writes f-strings: put f before the quote, and write the variable itself inside {braces}. Nothing to count, nothing to line up, and the braces can hold maths, function calls and formatting instructions too. This page is extra: it is not one of the posted homeworks.

f"…" Braces are holes

name = "Owen" age = 12 print(f"{name} is {age}. Next year: {age + 1}")
  • f before the first quote turns the braces on.
  • A brace holds a variable, or any expression: {age + 1}, {len(name)}.
  • Numbers need no str(); Python turns them into text for you.

: After the colon: how to show it

{total:.2f} → 37.50 {big:,} → 1,234,567 {item:<10} → pizza (padded) {qty=} → qty=3
  • .2f two decimals, , thousands separators.
  • <10 left-aligned in 10 spaces, >8 right-aligned in 8.
  • {qty=} prints the name and the value: a debugging trick.
