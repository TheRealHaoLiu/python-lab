Loops Lab

A loop runs the same block of lines again and again. for takes one turn per item in a list or a range(). while keeps taking turns as long as its check is True.

for One turn per item

for x in [1, 2, 3]: print(x)
  • Each turn, x is the next item, then the block runs.
  • range(1, 6) makes 1, 2, 3, 4, 5: it stops before the second number.
  • A colon : ends the for line, and the block is indented 4 spaces.

while Keep going while True

while coins < 1000: coins = coins + 67
  • Before every turn, Python checks the condition. False ends the loop.
  • Something in the block must change what the check looks at, or it never ends.
  • A loop inside a loop: the inner one runs all its turns on every outer turn.
