The Python Shell Lab

The shell is where you talk to Python one line at a time. The three >>> are Python asking for your next line. Type a value and it answers with the value; put a label on a value with = and it remembers it.

>>> Shell vs. script

>>> a = 1 >>> a + 2 3
  • In the shell, a line like a + 2 shows its answer at once.
  • In a saved script (hello.py) it shows nothing: write print(a + 2).
  • On your computer this is IDLE. Here it is the same Python, in the page.

% Types and operators

1 → int 1.0 → float "hi" → str
  • / divides and keeps the decimals; // keeps only the whole number.
  • % is the remainder: 29 % 7 is 1 (four sevens, one left over).
  • ** is a power: 2 ** 10 is 1024. * multiplies, and repeats a string: "ab" * 3.
