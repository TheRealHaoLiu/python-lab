Strings with Slots Lab

A string can have slots: marks where a value drops in later. One template, many sentences. Python has three ways to write a slot. The homework uses the first; the other two are what you will meet everywhere else.

%s The lecture's way

joke = "%s: a device for %s" print(joke % ("Knee", "finding furniture"))
  • %s marks a slot. % fills the slots, in order.
  • Two or more values go in parentheses: (a, b).
  • Too few or too many values is a TypeError.

{} .format()

joke = "{}: a device for {}" print(joke.format("Knee", "finding furniture"))
  • {} marks a slot. .format(…) fills them, in order.
  • No parentheses needed around the values: they are the arguments.

f"…" f-string (modern)

part = "Knee" print(f"{part}: a device for finding furniture")
  • Put f before the quotes, and the variable itself inside {…}.
  • Nothing to count or line up. Python 3.6 and newer; this is how most code is written today.
