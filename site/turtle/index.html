Python Lab · Turtle

Python with the turtle

The same lessons as the homework pages, but every program draws. A turtle starts in the middle of the screen; t.forward(100) walks it 100 steps, t.left(90) turns it. Loops make shapes, lists make colours, and a mistake is something you can see.

These scripts are plain Python: copy one into IDLE on your own computer and it draws there too.
