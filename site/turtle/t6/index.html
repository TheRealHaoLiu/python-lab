Loops with the turtle

A loop runs the same block of lines again and again. With a turtle you can see every turn: for takes one turn per number in a range(), while keeps taking turns as long as its check is True.

for One turn per item

for i in range(4): t.forward(100) t.left(90)
  • range(4) makes 0, 1, 2, 3: four turns, so four sides. A square in two lines.
  • range(1, 6) makes 1, 2, 3, 4, 5: it stops before the second number.
  • A colon : ends the for line, and the block is indented 4 spaces.

while Keep going while True

while size < 200: t.forward(size) t.left(90) size = size + 10
  • Before every turn, Python checks the condition. False ends the loop.
  • Something in the block must change what the check looks at, or the turtle walks for ever.
  • A loop inside a loop: the inner one draws a whole shape on every outer turn.
