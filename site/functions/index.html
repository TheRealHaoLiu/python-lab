Functions and Modules

A function is a recipe with a name. def writes the recipe once; calling it by name runs it, as many times as you like, with different ingredients each time. return hands the result back. And import math borrows a whole toolbox of functions someone else wrote.

def Write it, then call it

def double(n): return n * 2 print(double(21)) print(double(5))
  • n is a parameter: a label for whatever you pass in.
  • The indented block runs only when you call double(…).
  • return hands a value back. A function that only prints hands back None.

= Scope, defaults, import

import math def greet_all(times=1): print("Hi! " * times) greet_all() greet_all(3) print(math.sqrt(81))
  • A variable made inside a function is local: it lives only inside it.
  • times=1 is a default: used when the call leaves it out.
  • import math opens a toolbox; math.sqrt() uses one tool from it.
