Tuples & Lists Lab

Two ways Python keeps things in a row. A tuple is a row of sealed boxes: you can look but not touch. A list is a row of open boxes: you can swap, add and remove.

( ) Tuple: sealed

spells = ('fireball', 'ice blast')
  • Read one item: spells[0]
  • Slice a piece: spells[0:2]
  • Count items: len(spells)
  • Changing an item is an error.

[ ] List: open

order = ['soda', 'salad']
  • Everything a tuple can do, plus:
  • Change one: order[1] = 'fries'
  • Add to the end: order.append('cake')
  • Remove one: del order[0]
