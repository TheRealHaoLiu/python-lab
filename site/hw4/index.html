Lists Lab

A list is a row of numbered boxes. Python numbers them from 0, so the first box is [0], and you can also count from the back with [-1].

[ ] Make and read

bag = ['pen', 3, 'map']
  • Any mix of strings and numbers.
  • One item: bag[0] is 'pen', bag[-1] is 'map'.
  • A slice is a piece: bag[0:2] is ['pen', 3]. It stops before 2.
  • Count items: len(bag)

= Change

bag[1] = 'rope'
  • Swap one box: bag[1] = 'rope'
  • Add a box at the end: bag.append('torch')
  • Changing a box prints nothing. Print the list afterwards to see it.
