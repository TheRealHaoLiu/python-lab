Functions Lab

A function is a recipe with a name. def writes the recipe once; calling it by name cooks it, as many times as you like, with different ingredients each time. return hands the result back. And import borrows a whole toolbox of functions someone else wrote.

def Write it, then call it

def greet(name): print("Hello, " + name) greet("Mary") greet("Owen")
  • name is a parameter: a label for whatever you pass in.
  • The indented block runs only when you call greet(…).
  • Two calls, two hellos. One recipe.

↩ return, scope, import

def double(n): return n * 2 print(double(21))
  • return hands a value back. No return: the call gives None.
  • A variable made inside a function lives only inside it.
  • import time borrows a toolbox; time.asctime() uses one tool from it.

      Exploreimport time, import random
