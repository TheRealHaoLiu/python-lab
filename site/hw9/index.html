break & continue Lab

Loops make number sequences: squares, and the Fibonacci numbers, where each number is the sum of the two before it. Pick for when you know how many turns you need, while when a rule decides. And inside any loop, break and continue change what happens next.

for or while?

for i in range(20): # 20 turns, no more while total <= 100: # until the rule says stop
  • for with range(): you know the number of turns before you start.
  • while: you don't know how many turns. The check decides, before every turn.
  • a, b = b, a + b moves two numbers along at once: a gets the old b, b gets the sum.

break & continue

for i in range(1, 8): if i == 3: continue # skip the rest of THIS turn if i == 6: break # leave the loop for good print(i) # prints 1 2 4 5
  • continue jumps back to the top for the next turn. The lines below it don't run this time.
  • break ends the whole loop at once. Python goes on with the first line after it.
